# 性能测试

在 Prefill、Decode 和 MiniLB 实例启动完成后，可使用 `./sglang/client.sh` 脚本发起测试请求，验证实例是否正常运行。该脚本可在任一节点的容器中执行。

### 基础测试

#### 配置 client

打开 `sglang/client.sh` 脚本，按以下示例修改代码以关闭基准测试：

```shell
  false & [ "$LLM_LAUNCH_ENV" = "release" ] && {
      bench 32 2048 2048 17 3
      bench 32 2048 2048 17
      exit 0
  }
```

#### 启动基础测试

使用 `sglang/client.sh` 脚本启动测试任务，该脚本可在任意节点的容器中执行。

假设在 `192.168.0.1` 启动 MiniLB 实例，执行以下命令：

```shell
./sglang/client.sh \
	minimax-m2.sh \
    192.168.0.1:8001
```
**参数说明**

- 基础测试客户端脚本
- 模型名称：参考[配置模型文件](启动准备.md#配置模型文件)
- MiniLB实例IP及端口号

> **注意**：示例中的 `192.168.0.1:8001` 需替换为实际的 MiniLB 实例地址和端口号。`8001` 为默认端口号，可修改 `config.sh` 中的 `minilb_server_port` 参数来自定义端口。

查看模型回答是否合理。

### 基准测试

为了评估部署效果，可通过基准测试来展示当前部署模型的性能。

#### 配置 client

1. 打开 `sglang/client.sh` 脚本，将测试数据集的路径设置 `readonly dataset_path` 为容器中的路径：

   > **注意**：测试数据集已备份在容器内(/workspace/dataset/ShareGPT_V3_unfiltered_cleaned_split.json)。若文件不存在，可到 https://www.modelscope.cn/datasets/gliang1001/ShareGPT_V3_unfiltered_cleaned_split 自行下载

2. 将之前设置的 `false` 改为 `true`：

   ```shell
     true & [ "$LLM_LAUNCH_ENV" = "release" ] && {
         bench 32 2048 2048 17 3
         bench 32 2048 2048 17
         exit 0
     }
   ```
   
   **bench参数说明**
   
   - 最大并发
   - 输入token
   - 输出token
   - 请求率
   - 测试轮数(每轮测试数据不同，默认为1)

#### 启动基准测试

参照[基础测试](#基础测试)的方法，执行 `client.sh`。
